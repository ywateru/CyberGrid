# Node server third-party notices

Original license texts for every package in server/package-lock.json, including optional platform packages and build dependencies. Texts retain upstream bytes. Redis client packages use the MIT license; Redis service terms are separate.

Regenerate with `python3 scripts/release/collect-server-licenses.py` after `npm ci --prefix server`. Missing installed packages are read only from integrity-verified, lockfile-pinned public npm archives.
