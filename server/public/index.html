开发者入口

CyberGrid 是什么开始接入SDK 与测试 App连接方式部署自己的服务能力与边界

让设备之间，
直接使用彼此的服务。

CyberGrid 是多用户、多应用、多终端的连接协调服务。用 SDK 发现同账号、同应用的设备，发布 TCP 端口，再把远端服务映射到本机。

阅读接入文档GitHub Releases 下载

中央负责身份、设备状态和短期信令，不接收文件、同步内容或端到端业务字节。Logto 托管注册与登录，设备各自完成授权。

从一对设备开始

  1. 取得真实应用 ID。 使用启用 Device Flow 的 Logto Native Application，两个终端使用同一账号和同一应用 ID。
  2. 分别登录并公布服务。 在每台设备独立授权；用 Lab 或 CLI 发布本机 echo 服务，也可用 SDK Expose 自有 TCP 服务。
  3. 发现设备，建立映射。 选择远端设备与公开端口，通过 loopback 地址访问；业务协议与同步规则由你的应用处理。
macOS CLI · 解压后运行
# 填入你自己的 Logto Native Application ID
read -r CYBERGRID_APP_ID
export CYBERGRID_APP_ID
mkdir -p "$HOME/.config/cybergrid"
chmod 700 "$HOME/.config/cybergrid"
./cybergrid-macos login -app "$CYBERGRID_APP_ID" \
  -credentials "$HOME/.config/cybergrid/mac-logto-v4.json" -open-browser
./cybergrid-macos host -app "$CYBERGRID_APP_ID" \
  -credentials "$HOME/.config/cybergrid/mac-logto-v4.json" \
  -name mac -echo-port 0

另一端独立授权后使用 Devices / Map。查看端口映射，或从 Lab 双端测试开始；Android 完整 ZIP 携带 ADB 控制工具与许可。

直连优先，需要时回退

SDK 先尝试增强 WebRTC 直连；受 NAT 或网络限制无法直连时，再通过 Cloudflare Quick Tunnel 连接远端。两种路径均使用端到端 TLS 1.3 双向认证，业务密钥由终端持有。

macOS 默认使用 SDK 随附 provider，无需外装或 PATH 查找。Android 宿主将 SDK 资源安装至 nativeLibraryDir，按当前网络提供 DNS 与 App cache 环境。查看宿主集成要求。

已测 Wi-Fi / 4G 公网通信记录证实 Cloudflare 回退可用；不代表公网 WebRTC 直连或任意网络均可成功。Quick Tunnel 用于开发测试，没有可用性 SLA。

部署自己的 CyberGrid

一个长期运行的 Node.js 22 进程同时提供官网、控制台、管理后台与 API。协调状态只在同一进程有界内存中，不需要数据库，不使用多副本或 serverless Function。

在 server/ 复制 .env.example 并填写 Logto issuer、SPA 与目录 M2M 配置，然后执行 docker compose up --build -d。容器以非 root 用户运行；也可直接运行 Node。通过普通 HTTPS 反向代理连接服务，无需平台专用 SDK。

CYBERGRID_PUBLIC_ORIGIN 可留空：配置时固定使用该 HTTPS origin；留空时按本请求合法 Host / HTTP(S) 地址生成回跳，也支持代理覆盖的严格单值 X-Forwarded-Host / Proto。IP 限流始终只采用 socket 地址，外部代理后的请求共享代理 IP 配额。

JWT resource 独立固定：优先使用 LOGTO_RESOURCE，否则有公开 origin 时默认其加 /api，无公开 origin 时为 https://cybergrid.local/api。这是 OAuth 标识，不需 DNS，但应在 Logto 创建相同 resource。已有部署应显式保存原 resource，避免移除公开 origin 后改变 audience。

默认回跳为本次有效 origin 加 /console/callback/，可配置同源专用路径，并在 Logto 登记相同 URI。独立管理密钥 CYBERGRID_ADMIN_KEY 只保存在服务端，SMTP 在 Logto 配置。网站构建不获取 SDK 归档，下载直接来自 GitHub Releases。

查看完整 Node / Docker 部署步骤。设备控制台使用 Logto 查看当前用户，只读管理后台使用独立管理密钥。

接入前了解这些边界

  • 当前仅映射 TCP；端口必须由远端显式发布。设备在线表示心跳有效，不代表业务 TCP 已建立。
  • Lab 为测试版本：macOS 未公证，Android 使用测试签名并需保持前台；不提供后台长期保活保证。
  • 协调重启会丢失内存状态。SDK 可恢复注册和公布信息，旧业务 TCP 会中断；应用自行决定重试和同步。
  • 邮箱验证与找回密码由 Logto 托管；实际邮箱收件链路尚未完成验收。
  • 无 UDP、无损切路或应用业务字节自动重放。阅读完整平台限制。
