## objective

支持 Vercel Marketplace 的 KV 环境变量直接接入共享协调存储，在文档和一键部署入口说明现行产品名称，并将 Vercel 部署切换到该配置方式。连接方式切换以原资源验证 epoch 延续；用户随后授权为当前公开测试部署创建或连接专用 Upstash 免费测试资源。新数据库启用时明确记录 epoch 变化与客户端会话恢复要求，保留原资源供回退。

## verification

配置分组、显式选择、残缺与冲突拒绝、只读凭据不被采用。使用真实托管 REST 验证共享 epoch、会话和跨实例撤销，并证明同数据库 / namespace 在 TCP 与 REST 间切换不重置状态。专用测试资源只使用免费方案、不启用自动升级；预览与生产 namespace 分离，旧资源不删除。候选部署及正式域名检查通过后发布，并区分新数据库的预期 epoch 变化与连接方式迁移。不以本轮存储配置验证替代仍待完成的手机授权和 WAN 验收。
