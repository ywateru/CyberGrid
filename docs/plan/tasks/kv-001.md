## objective

支持 Vercel Marketplace 的 KV 环境变量直接接入共享协调存储，在文档和一键部署入口说明现行产品名称，并将 Vercel 生产部署切换到该配置方式。复用现有托管资源与 namespace，保留 epoch 和有效协调状态。

配置分组、显式选择、残缺与冲突拒绝、只读凭据不被采用。使用真实托管 REST 验证共享 epoch、会话和跨实例撤销，确认切换前后仍指向原数据库 / namespace。候选部署及正式域名检查通过后发布；不以本轮存储配置验证替代仍待完成的手机授权和 WAN 验收。
