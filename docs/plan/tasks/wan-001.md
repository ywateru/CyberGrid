## objective

使用 Mac Wi-Fi 与 Android 蜂窝网络，对已发布 Rust / Lab 与新 Redis 协调服务完成实机验收；测试通过后，将必要修复与准确测试记录更新到 GitHub 和线上。

## path

Rust SDK 与 Lab 的必要修复、公开验收记录及部署文档。原始运行记录、账号、设备标识、安装绑定和授权材料保留在仓库外，不进入 Git。

## verification

- 两端各自完成同账号、同 Native 应用的官方 Logto 授权，确认 Mac 使用 Wi-Fi、手机使用蜂窝网络。
- 验证设备互见、双向消息 ACK、双向 65,536 字节及 SHA256，并记录消息确认时的实际 transport。
- 分别记录默认串行、并行直连、隔离 WebRTC / iroh 与强制 Cloudflare 回退的实际结果；无法直连是网络观察，不伪报成功。
- 保留既有凭据与 grant 单所有者。不复制跨设备授权、不伪造登录、不以卸载、清数据或 force-stop 处理待完成授权。
- 独立复核测试证据与公开结论。仅针对必要修复执行相应回归；通过后提交、部署并核对上线源码。
