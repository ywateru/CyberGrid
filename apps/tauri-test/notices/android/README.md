# Android runtime notices

This directory records 78 external Maven artifacts: the existing 69 records plus nine runtime artifacts introduced by Lab 0.3.0's official Logto SDK integration. The original AAR/JAR archive checksum and upstream coordinate are recorded in dependency-index.json. Embedded license/copyright/notice files are copied unchanged. Where the binary archive does not embed its license text, upstream.pom (and parent.pom where applicable) records the exact version's published license declaration. Apache-2.0 declarations reference the complete official Apache license text in common/Apache-2.0.txt with its source URL and SHA256. No application data or credentials are part of this collection.

The new records retain exact Maven Central POM bytes and copied embedded notices, including OkHttp's public suffix notice. SLF4J's matching upstream MIT license and parent POM are included unchanged. Logto's published 3.0.0 POM declares MPL-2.0, while its matching upstream v3.0.0 LICENSE contains MIT. Both declarations and original texts are preserved: upstream-LICENSE is copied from the tagged source, and common/MPL-2.0.txt is the full official Mozilla license. The index records their URLs and SHA256 values, plus the matching Logto source location at https://github.com/logto-io/kotlin/tree/v3.0.0. This collection does not resolve the discrepancy by guessing a single license.
