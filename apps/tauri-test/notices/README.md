# Dependency notices

Actual LICENSE / COPYING / COPYRIGHT / NOTICE texts copied unchanged from the locked Cargo registry and installed npm packages. dependency-index.json records package version, upstream source and SHA256 of each copied file. The collection includes build/target-specific dependencies, so it may be broader than either binary. enum-assoc 1.4.2 has no original license text at its exact published commit: this distribution selects its declared Apache-2.0 alternative and includes explicitly labelled canonical standard text plus its original Cargo declaration and published author attribution, without inventing a copyright notice. Cloudflared's Apache-2.0 license, third-party notices, dual-platform resource manifest and exact upstream source/build records are copied unchanged from sdk-rust/provider-assets into notices/cloudflared. That folder's source-files-sha256.json binds the copied texts. The source archive also includes the SDK's pinned macOS/Android provider bytes and offline packaging/rebuild scripts.
